# DealZ Mission Statement

DealZ is a platform for users to be able to research any product easily, viewing price trends and ongoing deals. DealZ is for a user to be able to quickly find out if what they are paying for an item is the best possible price. It's to empower people to take control over their purchasing decisions: seamless browsing with strong data insights.

## What that means for the build

- Data quality is the product. A wrong price is worse than a missing one.
- The core question is "is this a good price, right now?", so history and context matter more than a raw number.
- Start narrow, consumer tech in Australia, and prove the matching before going wide.
